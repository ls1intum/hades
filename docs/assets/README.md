# Brand Assets

The Hades icon set. The mark is two pillars (the "gates") over three blocks (queued jobs).

| Asset | Use |
| ----- | --- |
| `hades-icon.svg` | Primary app icon on a dark rounded tile. Used in the top-level README header. Works on light and dark backgrounds. |
| `hades-mark-mono.svg` | Monochrome mark (`fill="currentColor"`); inherits the surrounding text color for inline or single-color contexts. |
| `hades-icon-favicon.svg` | Simplified favicon variant (solid bar). |
| `hades-icon-progress.svg` | Animated/progress variant (the third block is dimmed). |
| `png/hades-icon-progress-<size>.png` | Raster exports of the progress variant from 16px to 1024px (e.g. `-32`, `-180`, `-512`) for favicons, app icons, and social cards. |

Brand colors: background `#191C24`, pillars `#F2EFE9`, blocks `#FF6A3D`.
